RAZE WAHEED WEBSITE
===================

Files:
- index.html
- styles.css
- script.js

How to use:
1. Open index.html in a browser to preview.
2. Replace the visual placeholders with approved photos.
3. Replace # social links with the official profile URLs.
4. Connect the contact form to an email/form backend before publishing.

The copy intentionally avoids unverified titles and credentials. Add only facts you can verify.
